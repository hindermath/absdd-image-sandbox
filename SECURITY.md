# Sicherheitsmeldungen / Security Reports

## Deutsch

Bitte melde vermutete Schwachstellen nicht als oeffentliches Issue. Nutze,
falls auf der aktiven Hosting-Plattform verfuegbar, den privaten Security-
Advisory-Kanal dieses Repositories. Ist dieser Kanal nicht verfuegbar, stoppe
und bitte den Repository Owner um einen vertraulichen Meldeweg; sende keine
Secrets oder produktiven Daten. Empfang wird als Ziel innerhalb von sieben
Kalendertagen bestaetigt. Triage, Schweregrad, Patch und koordinierte
Veroeffentlichung folgen `docs/security/vulnerability-disclosure.md`.

Diese Datei ist eine repositorylokale Prozessbeschreibung, keine Zusage einer
gesetzlichen Meldung und keine Rechtsbewertung.

## English

Do not report suspected vulnerabilities in a public issue. Use this
repository's private security-advisory channel when the active hosting
platform provides it. If unavailable, stop and ask the repository owner for a
confidential channel; do not send secrets or production data. The target is to
acknowledge receipt within seven calendar days. Triage, severity, patching,
and coordinated disclosure follow `docs/security/vulnerability-disclosure.md`.

This is a repository-local process, not a legal-notification promise or legal
assessment.
