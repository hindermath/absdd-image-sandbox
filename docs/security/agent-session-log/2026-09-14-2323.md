## Laufzeit und Grenzen / Runtime and boundaries

Die kurzlebige Startsession hielt die Podman-VM nicht aktiv. Eine offen gehaltene
Terminalsession stabilisierte den Betrieb. Der temporäre Mount wurde von der
macOS-Symlinkschreibweise `/tmp` auf den aufgeloesten Pfad `/private/tmp`
umgestellt. Keine Image-, Compose-Produkt-, Rechte- oder Netzwerkregel geaendert.
Die bereits genehmigte Git-Vertrauensausnahme galt nur pro Prozess fuer
`/ade-dev-sandbox`, nie global. Ein falsch als einzelner String uebergebenes
PowerShell-Repo-Array wurde durch einzelne erfolgreiche CheckOnly-Aufrufe ersetzt.

Abschluss: Syntaxcheck und Compose-Vorschau, dann
`compose-down-with-audit.sh --podman` ohne `-v`, Exit 0. Pilotcontainer entfernt,
alle sechs benannten Volumes erhalten, Podman-VM wieder gestoppt. Das bestehende
Pilotimage bleibt erhalten. Keine neuen Agenten- oder Provideranmeldungen.

The persistent terminal session and resolved temporary mount path enabled the
existing pilot image to run. No protection was weakened. Audit export preceded
normal shutdown; the container was removed, all six volumes and the image were
retained, and the VM was stopped.
