# Cloud-Compliance-Assurance

**DE:** BSI C3A/C5 und eine inhaltliche Cloud-Compliance-Pruefung sind fuer den
aktuellen nichtkommerziellen Ausbildungs- und Beispielscope `N/A`. Die Sandbox
nutzt GitHub, CI, Paketquellen und Registries als Entwicklungsinfrastruktur;
sie betreibt aber keine Cloud-Produkt-Runtime, kein Hostingangebot und keinen
Managed Service. Der synthetische C5-Fall des Assurance-Presets prueft nur die
sichere Blockierung unzulaessiger C5- oder Zertifizierungsbehauptungen. Er ist
kein C5-Test und keine Anbieter-Compliance-Aussage.

**EN:** BSI C3A/C5 and a substantive cloud-compliance assessment are `N/A` for
the current non-commercial training and example scope. The sandbox uses GitHub,
CI, package sources, and registries as development infrastructure, but it does
not operate a cloud product runtime, hosting service, or managed service. The
Assurance preset's synthetic C5 case only tests safe blocking of invalid C5 or
certification claims. It is not a C5 test or provider-compliance statement.

Regulatorische Scope-Wiedervorlage / Regulatory scope review: `2026-12-31`.
Frueherer Trigger / Earlier trigger: commercial use, market placement, customer
handover, support contract, cloud product runtime, managed service, provider
assurance, registry distribution, or a changed manufacturer/steward role.
Mapping: GAP-025, AR-007.
