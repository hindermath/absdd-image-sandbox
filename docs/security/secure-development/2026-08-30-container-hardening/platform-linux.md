Status: `Open`. Owner: Repository Maintainer. Reviewer: Security Review.

Podman, PowerShell 7 und VS Code Dev Containers verfuegbar. Der Linux-Container
auf einem macOS-Host ist kein Ersatz und es wurde kein `N/A` oder `Pass`
abgeleitet. / No real Linux host with rootless Podman, PowerShell 7, and VS
Code Dev Containers was available. A Linux container on macOS is not a
substitute; no N/A or Pass was inferred.
